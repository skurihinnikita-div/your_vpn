# your_vpn

### VPN-клиент для обхода блокировок · Android и Windows

*VLESS · AmneziaWG (AWG) · WDTT (VK-TURN) — три транспорта в одном приложении: заблокировали один способ, переключаешься и работаешь дальше.*

</div>

---

## О проекте

**your_vpn** — клиент с несколькими движками обхода блокировок. В одном приложении сразу несколько
транспортов, поэтому когда один способ перестаёт работать, рядом есть другой:

- **VLESS** — через **Xray** / **sing-box** (TCP, WS, gRPC, HTTPUpgrade, XHTTP, TLS, Reality, uTLS-отпечатки);
- **AmneziaWG (AWG)** — обфусцированный WireGuard (Jc/Jmin/Jmax, S1–S4, H1–H4, I1), устойчив к DPI;
- **WDTT (VK-TURN)** — туннель через звонки VK, ходит там, где обычный UDP закрыт.

Поддерживаются **Android** и **Windows**. Один и тот же движок и один и тот же формат подписки на
всех платформах.

Всем желающим проверить full подписку https://t.me/VPN_onlimbot

## Возможности

- **Несколько движков и протоколов** в одном приложении — ядро подбирается под транспорт автоматически.
- **Единый импорт подписок**: ссылки `vless://`, AmneziaWG `.conf`, `qwdtt://`, а также единый JSON
  каталог `vpn.servers.full`, где в одном файле лежат сразу `vless`, `awg` и `wdtt`.
- **Данные подписки**: имя, **ID**, срок действия и **«Поддержка»** прямо в карточке подписки
  (панель отдаёт `profile-title`, `profile-id`, `subscription-userinfo`, `support-url`).
- **Понятный список серверов**: пинг, флаги, страны и **цветовая подсветка по протоколу**
  (VLESS — как есть, Amnezia — пастельно-зелёный, WDTT — пастельно-красный), компактные строки.
- **Раздельное туннелирование**: через VPN идёт только выбранный список приложений (Android).
- **Авто-выбор** быстрейшего сервера в один тап.
- **Оформление**: отдельный раздел настроек — динамическая/светлая тема и цвета; на Android
  системные цвета (Material You) включены по умолчанию.
- **Стабильный фон**: на Android приложение просит исключить себя из оптимизации батареи и держит
  WakeLock, чтобы VPN не отваливался в простое; на Windows TUN поднимает привилегированная служба.
- **Без утечек**: перехватываются и IPv4, и IPv6.

## Скачать

Готовые сборки — в разделе **Releases**. Для ручной установки используйте файлы из папки `deliverables/`
(в репозиторий она не входит).

**Android** (файл `.apk`):
- `your_vpn-universal.apk` — подходит любому телефону (если не знаете, что выбрать — берите этот);
- `your_vpn-arm64-v8a.apk` — большинству современных телефонов;
- `your_vpn-armeabi-v7a.apk` — старым 32-битным;
- `your_vpn-x86_64.apk` — эмуляторам и редким устройствам на Intel.

**Windows** (файл `.exe`, x64):
- `...-installer.exe` — обычная установка (ярлык в «Пуске», удаление в «Программах»);
- `...-portable.exe` — без установки: запустил и работает.

> Имя файлов соответствует версии, например `your_vpn-1.4-universal.apk`.

## Установка

**Android.** Откройте `.apk` → разрешите «Установка из неизвестных источников» → установите.
Если стояла сборка с другим ключом подписи, сначала удалите старое приложение.

**Windows.** Запустите `...-installer.exe` (при установке один раз потребуются права администратора —
так регистрируется фоновая служба для TUN). Либо используйте portable-версию без установки.

---

## Как добавить подписку

1. Скопируйте ссылку на подписку.
2. В приложении нажмите **«+»** и выберите добавление по ссылке/из буфера.
3. Серверы появятся в списке — выберите или включите «Авто».

Поддерживаются обычные панельные подписки (Remnawave/Happ-совместимые) и **единый JSON**
`vpn.servers.full`, где сразу приходят VLESS, AmneziaWG и WDTT.

## Сборка (кратко)

Требуется JDK 21, Android SDK + NDK, Go, MinGW-w64 (для Windows-ядер).

**Android:**
```
cd olcvpn-client-main/YPtun
./gradlew :androidApp:assembleRelease
```

**Windows:**
```
cd olcvpn-client-main/YPtun
./gradlew :desktopApp:createDistributable
powershell -File desktopApp/packaging/windows/build-installer.ps1
powershell -File desktopApp/packaging/windows/build-portable.ps1
```

Windows-служба (Go):
```
cd olcvpn-client-main/YPtun/windows-service
go build -o your_vpn_service.exe .
```
